## FAQ

**Will it make up answers?**  
The assistant is instructed to answer from your approved material and visibly falls back when it cannot find support. AI can never be guaranteed error-free, so you approve and test the final knowledge base before launch.

**Do I need an OpenAI API key?**  
No for Starter. Standard and Advanced can use a key that you own and fund. It stays on the server, not in browser code.

**Can you add it to WordPress, Webflow, Wix, Shopify, or a custom site?**  
The widget uses one script tag and works on sites that allow custom scripts. Platform access and plan restrictions must be available.

**Are hosting and monthly API fees included?**  
No. I can deploy to your compatible account in the package stated above. You pay third-party fees directly.

**Can I resell the source code?**  
The standard order licenses one configured deployment for one named business. Template resale, SaaS resale, and additional client deployments require a separate agreement.
